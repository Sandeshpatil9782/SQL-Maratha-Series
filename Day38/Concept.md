# Day 38 – BETWEEN

# 🏕️ SQL Swarajya Goshti – BETWEEN

## 🧠 Concept

रायगडाच्या पायथ्याशी एका मावळ्याचं छोटंसं घर होतं.

एका दिवशी त्याच्यासमोर तीन पर्याय होते.

पहिल्या ताटात फक्त **५ भाकऱ्या** – कमी.
पोट भरायचं कठीण.

दुसऱ्या ताटात **१० ते २० भाकऱ्या**, भाजी आणि पाणी.
कुटुंब आनंदाने जेवत होतं.

तिसऱ्या ताटात **५० भाकऱ्या, सोनं आणि संपत्ती**.
पण त्याकडे कुणाचं लक्ष नव्हतं.

मावळ्याने मधला मार्ग निवडला.

कारण...

**जास्तीची आस नको, कमीची चिंता नको.**
**समाधान हाच खरा BETWEEN.**

---

# 💻 SQL Syntax

```sql
SELECT *
FROM Life
WHERE Happiness BETWEEN 10 AND 20;
```

---

# 🔍 Explanation

`BETWEEN` वापरून एखादी value ठराविक range मध्ये आहे का ते तपासलं जातं.

हे दोन्ही values (Start आणि End) समाविष्ट (Inclusive) असतात.

वरील Query मध्ये:

- 10 ✔️
- 15 ✔️
- 20 ✔️
- 9 ✖️
- 21 ✖️

---

# 🌍 Real World Example

एका कंपनीला फक्त ₹10,000 ते ₹20,000 पगार असलेले Employees शोधायचे आहेत.

```sql
SELECT *
FROM Employees
WHERE Salary BETWEEN 10000 AND 20000;
```
