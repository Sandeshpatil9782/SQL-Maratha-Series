# Day 50 – INDEX ⚔️

## ⚔️ Concept: माहिती पटकन शोधण्यासाठी INDEX

SQL मध्ये **INDEX** हा database table मधील data शोधण्याची प्रक्रिया वेगवान करण्यासाठी वापरला जातो.

मोठ्या table मध्ये हजारो किंवा लाखो records असतील, तर प्रत्येक row एक-एक करून तपासणे वेळखाऊ ठरू शकते.

`INDEX` मुळे database ला आवश्यक data **जलद locate** करता येतो.

म्हणजेच...

**Without INDEX → प्रत्येक record शोधत जा**

**With INDEX → योग्य data पटकन शोधा**

---

## 🏰 Historical Analogy

समजा महाराष्ट्रात **100+ किल्ले** आहेत.

एखाद्याने विचारलं:

**"पन्हाळा कुठे आहे?"**

जर प्रत्येक किल्ल्याची माहिती एक-एक करून तपासावी लागली, तर वेळ लागेल.

पण तुमच्याकडे व्यवस्थित **FORT INDEX** असेल तर:

**पन्हाळा → लगेच location → पाणी → मार्ग → गुप्त दरवाजा**

म्हणजे माहिती व्यवस्थित indexed असल्यामुळे decision घेण्याचा वेळ कमी होतो.

> **माहिती व्यवस्थित असेल तर वेग वाढतो. ⚔️**
