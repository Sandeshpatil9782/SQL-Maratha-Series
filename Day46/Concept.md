# Day 46 – REVOKE ⚔️

## ⚔️ Concept: अधिकार काढून घेणे म्हणजे विश्वास संपणे

SQL मध्ये **GRANT** वापरून User ला Permission दिली जाते.

पण जेव्हा एखाद्या User ला दिलेला Access आता ठेवायचा नसतो,
तेव्हा **REVOKE** वापरला जातो.

म्हणजेच...

**GRANT → अधिकार द्या**

**REVOKE → दिलेला अधिकार काढून घ्या**

---

## 🛡️ Historical Analogy

एकदा एखाद्या विश्वासू व्यक्तीला
राज्याच्या कामाची जबाबदारी आणि अधिकार दिले.

पण त्याच व्यक्तीवरचा विश्वास संपला,
तर दिलेले अधिकार परत घ्यावे लागतात.
