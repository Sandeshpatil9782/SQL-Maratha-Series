# Day 37 : ⚔️ SQL Swarajya Goshti
# DISTINCT

## 📖 Swarajya Story

रायगडाच्या दरबारात अनेक सरदार, मावळे आणि मानकरी उपस्थित होते.

सगळ्यांचा पोशाख जवळपास सारखाच...
सगळ्यांच्या पगड्या सारख्याच...
सगळे एकाच स्वराज्यासाठी उभे...

पण जेव्हा नेतृत्वाचा प्रश्न आला,
तेव्हा संपूर्ण दरबारात एकच नाव घुमलं...

**"छत्रपती शिवाजी महाराज!"**

गर्दी कितीही मोठी असली,
तरी खरी ओळख नेहमी वेगळीच असते.

SQL मधील **DISTINCT** सुद्धा हेच शिकवतो.

Duplicate Values काढून टाकून,
फक्त Unique Values दाखवतो.

> **नक्कल नाही... अस्सलच हवा. ⚔️**

---

## 💻 SQL Syntax

```sql
SELECT DISTINCT column_name
FROM table_name;
```

---

## 🛡️ Example

```sql
SELECT DISTINCT Leader
FROM Swarajya;
```

---

## 📊 Example Output

| Leader |
|---------|
| Shivaji Maharaj |

---

## 💡 Real-Life Meaning

- गर्दीत मिसळणं सोपं असतं.
- पण स्वतःची वेगळी ओळख निर्माण करणं कठीण असतं.
- DISTINCT आपल्याला Unique Value दाखवतो.
- आयुष्यातही स्वतःचं वेगळेपण जपा.
