# Day 45 – GRANT ⚔️

## ⚔️ Concept: अधिकार दिला म्हणजे विश्वास दिला

SQL मध्ये **GRANT** म्हणजे एखाद्या User किंवा Role ला Database Object वर विशिष्ट **Permissions / Privileges** देणे.

म्हणजेच...

**अधिकार दिला**  
=  
**जबाबदारीसोबत विश्वास दिला**

फक्त सत्ता देणे नाही,  
तर योग्य व्यक्तीला योग्य कामाची **Access** देणे.

---

## 🛡️ Swarajya Analogy

राजदरबारात एखाद्या विश्वासू योद्ध्याला  
महत्त्वाची जबाबदारी दिली जाते.

त्याला अधिकार मिळतो...

पण त्या अधिकारासोबत  
**जबाबदारी आणि विश्वास** देखील येतो.

SQL मध्येही तसंच—

```sql
GRANT ALL PRIVILEGES
ON Fort_Panhala
TO Baji_Prabhu;
